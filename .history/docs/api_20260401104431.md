## 一、HTTP API 接口

> Base URL 通过设置项 `api_base_url` 配置。为空时自动切换到 Mock 模式。
> 所有接口 Content-Type: `application/json`，超时 15s，连接超时 5s，自动重试 1 次（5xx/网络错误）。

### 1.1 设备归属同步

**`POST /api/devices/sync`**

启动时执行，上报当前设备列表，服务端返回需要清理的设备（被其他客户端占用）。

#### 请求参数

| 字段            | 类型               | 必填 | 说明                               |
| --------------- | ------------------ | ---- | ---------------------------------- |
| `clientId`      | `string`           | ✅   | 客户端唯一标识（机器指纹 SHA-256） |
| `online`        | `DeviceSyncItem[]` | ✅   | 当前在线的设备列表                 |
| `offline_local` | `string[]`         | ✅   | 当前离线的设备 hw_serial 列表      |

**DeviceSyncItem**:

| 字段        | 类型     | 说明                                                  |
| ----------- | -------- | ----------------------------------------------------- |
| `hw_serial` | `string` | 硬件序列号                                            |
| `serial`    | `string` | ADB 序列号                                            |
| `state`     | `string` | 设备状态：`"Device"` / `"Offline"` / `"Unauthorized"` |

```json
{
  "client_id": "auto-abc123def456",
  "online": [{ "hw_serial": "HW123456", "serial": "192.168.1.100:5555", "state": "Device" }],
  "offline_local": ["HW789012"]
}
```

#### 响应参数

| 字段        | 类型       | 说明                                |
| ----------- | ---------- | ----------------------------------- |
| `to_remove` | `string[]` | 需要从本地删除的设备 hw_serial 列表 |

```json
{
  "to_remove": ["HW789012"]
}
```

### 1.2 手机号绑定

**`POST /mttl_tools/v1/meituanTraffic/client/bind`**

将手机号绑定到当前客户端（互斥策略：同一手机号只能绑一个客户端）。

#### 请求参数

| 字段        | 类型       | 必填 | 说明                     |
| ----------- | ---------- | ---- | ------------------------ |
| `clientId`  | `string`   | ✅   | 客户端 ID                |
| `mobiles`   | `string[]` | ✅   | 要绑定的手机号列表       |
| `forceBind` | `bool`     | ✅   | 是否强制绑定（忽略冲突） |

```json
{
  "clientId": "auto-abc123def456",
  "mobiles": ["13800138000", "13900139000"],
  "forceBind": false
}
```

#### 响应参数

| 字段        | 类型              | 说明             |
| ----------- | ----------------- | ---------------- |
| `conflicts` | `PhoneConflict[]` | 存在冲突的手机号 |
| `taskItems` | TaskItem[]        | 任务列表         |

**PhoneConflict**:

| 字段       | 类型     | 说明                        |
| ---------- | -------- | --------------------------- |
| `mobile`   | `string` | 冲突的手机号                |
| `clientId` | `string` | 当前持有该手机号的客户端 ID |

**TaskItem**:

| 字段     | 类型     | 说明   |
| -------- | -------- | ------ |
| `taskId` | `string` | 任务ID |

```json
{
  "conflicts": [{ "mobile": "13900139000", "clientId": "auto-xyz789" }],
  "taskItems": ["1231", "123123"]
}
```

### 1.4 按手机号拉取任务

**`POST /api/tasks/by-phones`**

根据已绑定的手机号列表，拉取所有关联的任务定义。

#### 请求参数

| 字段        | 类型       | 必填 | 说明               |
| ----------- | ---------- | ---- | ------------------ |
| `client_id` | `string`   | ✅   | 客户端 ID          |
| `phones`    | `string[]` | ✅   | 已绑定的手机号列表 |

```json
{
  "client_id": "auto-abc123def456",
  "phones": ["13800138000", "13900139000"]
}
```

#### 响应参数

| 字段          | 类型                     | 说明                  |
| ------------- | ------------------------ | --------------------- |
| `phone_tasks` | `Map<string, TaskDef[]>` | 手机号 → 任务定义列表 |

**TaskDef**:

| 字段     | 类型        | 说明     |
| -------- | ----------- | -------- |
| `id`     | `string`    | 任务 ID  |
| `name`   | `string`    | 任务名称 |
| `cities` | `CityDef[]` | 城市列表 |

**CityDef**:

| 字段       | 类型       | 说明       |
| ---------- | ---------- | ---------- |
| `name`     | `string`   | 城市名称   |
| `poi`      | `string`   | POI 地点   |
| `keywords` | `string[]` | 关键词列表 |

```json
{
  "phone_tasks": {
    "13800138000": [
      {
        "id": "task-001",
        "name": "北京任务",
        "cities": [
          {
            "name": "北京",
            "poi": "天安门",
            "keywords": ["美食", "酒店", "景点"]
          }
        ]
      }
    ]
  }
}
```

## 二、MQTT 通信协议

> 协议层：MQTT v3.1.1，QoS: AtLeastOnce，Clean Session: true
> Broker 地址可配置，默认 `39.98.170.208:30002`
> Topic 格式：`automatex/{client_id}/{suffix}` 或 `automatex/{suffix}`（广播）

### 2.1 连接配置

| 参数          | 类型      | 默认值          | 说明           |
| ------------- | --------- | --------------- | -------------- |
| `broker_host` | `string`  | `39.98.170.208` | Broker 地址    |
| `broker_port` | `u16`     | `30002`         | Broker 端口    |
| `client_id`   | `string`  | 机器指纹        | 客户端唯一标识 |
| `username`    | `string?` | `automatex`     | 认证用户名     |
| `password`    | `string?` | —               | 认证密码       |
| Keep Alive    | —         | `30s`           | 心跳间隔       |

### 2.2 订阅 Topic

连接成功后自动订阅：

| Topic                                | 说明                                  |
| ------------------------------------ | ------------------------------------- |
| `automatex/{client_id}/downstream/#` | 下行通配 — 接收所有发给本客户端的消息 |
| `automatex/broadcast/#`              | 广播通配 — 接收全局广播消息           |

---

### 2.3 上行 Topic（客户端 → 服务端）

#### 2.3.1 设备上线事件

**Topic**: `automatex/{client_id}/upstream/device/online`

```json
{
  "client_id": "auto-abc123",
  "hw_serials": ["HW123456"],
  "ts": 1743487200
}
```

#### 2.3.2 设备下线事件

**Topic**: `automatex/{client_id}/upstream/device/offline`

```json
{
  "client_id": "auto-abc123",
  "hw_serials": ["HW123456"],
  "ts": 1743487200
}
```

#### 2.3.3 心跳上报

**Topic**: `automatex/{client_id}/upstream/heartbeat`

每 30 秒自动发送，包含在线设备和执行中任务。

| 字段              | 类型       | 说明                      |
| ----------------- | ---------- | ------------------------- |
| `ts`              | `int64`    | Unix 时间戳               |
| `devices`         | `string[]` | 在线设备的 hw_serial 列表 |
| `tasks_executing` | `string[]` | 执行中的任务 ID 列表      |

```json
{
  "ts": 1743487200,
  "devices": ["HW123456", "HW789012"],
  "tasks_executing": ["task-001"]
}
```

#### 2.3.4 任务状态事件

**Topic**: `automatex/{client_id}/upstream/task/event`

```json
{
  "client_id": "auto-abc123",
  "task_id": "task-001",
  "action": "started",
  "ts": 1743487200
}
```

#### 2.3.5 LWT 遗嘱消息（异常断开自动发送）

**Topic**: `automatex/{client_id}/upstream/offline`

```json
{
  "client_id": "auto-abc123",
  "reason": "unexpected_disconnect"
}
```

### 2.4 下行 Topic（服务端 → 客户端）

> **消息过滤规则**：
>
> 1. 携带 `ts` 字段且 `ts < connect_ts` 的消息会被跳过（过滤旧消息）
> 2. 携带 `source` 字段且 `source == client_id` 的消息会被跳过（防回环）

#### 2.4.1 踢设备下线

**Topic**: `automatex/{client_id}/downstream/device/kick`

服务端指示客户端释放指定设备。

| 字段         | 类型       | 必填 | 说明                                            |
| ------------ | ---------- | ---- | ----------------------------------------------- |
| `hw_serials` | `string[]` | ✅   | 需要释放的设备 hw_serial 列表（校验：非空数组） |
| `ts`         | `int64`    |      | 时间戳（用于过滤旧消息）                        |
| `source`     | `string`   |      | 发送方 client_id（用于回环校验）                |

```json
{
  "hw_serials": ["HW123456", "HW789012"],
  "ts": 1743487200,
  "source": "admin-server"
}
```

**前端事件**: `mqtt-device-kick` — 将整个 payload 透传

---

#### 2.4.2 任务数据变更通知

**Topic**: `automatex/{client_id}/downstream/task/reload`

服务端通知客户端重新加载任务数据。

| 字段      | 类型     | 必填 | 说明                                                         |
| --------- | -------- | ---- | ------------------------------------------------------------ |
| `action`  | `string` | ✅   | 操作类型：`"reload_all"` / `"reload_task"` / `"delete_task"` |
| `task_id` | `string` | 条件 | `reload_task` / `delete_task` 时必填                         |
| `ts`      | `int64`  |      | 时间戳                                                       |
| `source`  | `string` |      | 发送方 client_id                                             |

**校验规则**：

- `action` 必须是 `reload_all` / `reload_task` / `delete_task` 之一
- `reload_task` / `delete_task` 必须携带非空 `task_id`
- `reload_all` 不应携带 `task_id`

```json
{
  "action": "reload_task",
  "task_id": "task-001",
  "ts": 1743487200
}
```

**前端事件**: `mqtt-task-reload` — 将整个 payload 透传

---

#### 2.4.3 手机号解绑通知

**Topic**: `automatex/{client_id}/downstream/phones/unbind`

服务端通知客户端指定手机号被抢占/解绑。

| 字段     | 类型       | 必填 | 说明                                 |
| -------- | ---------- | ---- | ------------------------------------ |
| `phones` | `string[]` | ✅   | 被解绑的手机号列表（校验：非空数组） |
| `ts`     | `int64`    |      | 时间戳                               |
| `source` | `string`   |      | 发送方 client_id                     |

```json
{
  "phones": ["13800138000"],
  "ts": 1743487200
}
```

**前端事件**: `mqtt-phones-unbind` — 将整个 payload 透传

---

### 2.5 广播 Topic

#### 2.5.1 全局任务变更广播

**Topic**: `automatex/broadcast/task/update`

全局广播（所有客户端接收），格式同 2.4.2 **任务数据变更通知**。

| 字段      | 类型     | 必填 | 说明                                               |
| --------- | -------- | ---- | -------------------------------------------------- |
| `action`  | `string` | ✅   | `"reload_all"` / `"reload_task"` / `"delete_task"` |
| `task_id` | `string` | 条件 | `reload_task` / `delete_task` 时必填               |

**前端事件**: `mqtt-task-reload`（复用同一事件）

## 三、Tauri 前端命令（IPC）

> 前端通过 `invoke("command_name", { args })` 调用，返回 `Promise<T>`。
> Tauri v2 自动将 snake_case 命令名转为 camelCase 前端调用名。
> 所有命令已统一错误格式：`Result<T, String>`。

---

### 3.1 设备管理

| 参数      | 类型     | 说明                              |
| --------- | -------- | --------------------------------- |
| `address` | `string` | 设备地址，如 `192.168.1.100:5555` |

#### `get_device_info`

## 四、Tauri 事件系统（Event Bus）

> 后端通过 `app_handle.emit()` 发送，前端通过 `listen()` 监听。

| 事件名                   | 方向               | Payload                    | 说明                                                                               |
| ------------------------ | ------------------ | -------------------------- | ---------------------------------------------------------------------------------- |
| `devices-changed`        | Backend → Frontend | `()`                       | 设备列表变更通知                                                                   |
| `mqtt-status`            | Backend → Frontend | `string`                   | MQTT 状态变更：`"connected"` / `"connecting"` / `"disconnected"` / `"error:{msg}"` |
| `mqtt-device-kick`       | Backend → Frontend | `{ hw_serials: string[] }` | 收到踢设备指令                                                                     |
| `mqtt-task-reload`       | Backend → Frontend | `{ action, task_id? }`     | 任务数据变更通知                                                                   |
| `mqtt-phones-unbind`     | Backend → Frontend | `{ phones: string[] }`     | 手机号被解绑通知                                                                   |
| `mqtt-message`           | Backend → Frontend | `{ topic, payload }`       | 未匹配路由的 MQTT 消息                                                             |
| `task://update`          | Backend → Frontend | `{ tasks: TaskSummary[] }` | 任务状态全量快照推送                                                               |
| `risk-control`           | Backend → Frontend | `{ ... }`                  | 风控事件通知                                                                       |
| `require-phone-bind`     | Backend → Frontend | `()`                       | 通知前端跳转到手机号绑定页面                                                       |
| `startup-sync-status`    | Backend → Frontend | `string`                   | 启动同步进度通知                                                                   |
| `account://sync-changed` | Backend → Frontend | `{ phones: string[] }`     | 已同步手机号变更                                                                   |
| `scrcpy-session-state`   | Backend → Frontend | `ScrcpySessionState`       | 投屏会话状态变化                                                                   |
| `scrcpy-text-route`      | Backend → Frontend | `{ serial, route }`        | 文本输入路由通知                                                                   |
| `scrcpy-clipboard`       | Backend → Frontend | `{ serial, text }`         | 设备剪贴板同步                                                                     |

**ScrcpySessionState payload**:

| 字段               | 类型      | 说明                                                                      |
| ------------------ | --------- | ------------------------------------------------------------------------- |
| `serial`           | `string`  | 设备序列号                                                                |
| `phase`            | `string`  | `"starting"` / `"streaming"` / `"stalled"` / `"recovering"` / `"stopped"` |
| `width`            | `u32`     | 屏幕宽度                                                                  |
| `height`           | `u32`     | 屏幕高度                                                                  |
| `recover_reason`   | `string?` | 恢复原因                                                                  |
| `last_frame_at_ms` | `u64?`    | 最后一帧相对时间 (ms)                                                     |

## 附录：常量定义

### 任务状态 (`task_status`)

| 值          | 说明   |
| ----------- | ------ |

| `executing` | 执行中 |
| `paused`    | 已暂停 |

| 值        | 说明   |
| --------- | ------ |
| `pending` | 未开始 |
| `active`  | 执行中 |
| `done`    | 已完成 |

### 关键词状态 (`keyword_status`)

| 值        | 说明   |
| --------- | ------ |
| `pending` | 未开始 |
| `run`     | 执行中 |
| `ok`      | 已完成 |

### 设备状态 (`device_state`)

| 值             | 说明   |
| -------------- | ------ |
| `Device`       | 在线   |
| `Offline`      | 离线   |
| `Unauthorized` | 未授权 |
| `unknown`      | 未知   |

| 值     | 说明      |
| ------ | --------- |

| 值          | 说明     |
| ----------- | -------- |

| 值        | 说明   |
| --------- | ------ |
